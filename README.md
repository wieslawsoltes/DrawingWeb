# DrawingWeb

A reusable data-bound drawing and diagramming engine, web control, and Blazor component.

Initial implementation and release qualification are being committed to this repository. The first release is `0.1.0-alpha.1` and will include ESM/CommonJS/declaration entry points, a GitHub Pages studio, self-contained Blazor static assets, tests, and npm/NuGet release workflows.

**Compatibility boundary:** this is an independent implementation, not Microsoft Visio. VSDX/VDX interchange and a loss-preserving VSDX editing contract are implemented; complete Visio rendering, ShapeSheet, binary VSD, and native database-driver parity are not claimed. Detailed capabilities and limitations accompany the source.
